# OST 1.2.6

正式版本：`1.2.6`，发布日期：2026-11-06。

## 主要更新

- 新增独立参数扫描面板及扫描流量表，参数流量不再混入总数据看板；持久化及历史恢复保留流量来源。
- 支持参数名探测、已有参数值扫描，以及 `$1$`、`$2$` 等自定义位置；每个位置选择已有 Payload 字典，不同编号按全部组合生成请求。
- 支持多个端点追加、不同模式混合提交、按端点保留草稿及配置、实时字典刷新、标记删除与恢复、扫描进度展示。
- 普通浏览器扫描与参数浏览器扫描使用独立工作队列及 Browser ID。相同 Browser ID 内串行执行，全局暂停仍对两类任务生效。
- 浏览器来源端点可以发起参数扫描；HTTP 与浏览器来源的相同端点独立保留。
- 修复数据看板初始化布局、右键菜单及独立请求/响应查看器的回归问题，并补充多 URL 导入及混合请求模式测试。

## 浏览器请求修复

- 自动发现解释器时，若候选 Python 缺少 DrissionPage，尝试后续候选；导航已经开始后的异常不会通过更换解释器重复发送请求。
- 仅返回对应的网络响应，不再用浏览器渲染 DOM 或内置错误页拼接、替代响应正文；无法获取正文时使用明确的响应标记。
- 保留 Cookie 挑战页处理，但不单凭 401、412 或 413 状态码触发重放；自动重放、Cookie 更新和失败响应均有边界处理。
- 卡巴斯基等已识别的浏览器辅助请求不作为目标响应或挑战脚本证据。
- 修复挑战页慢 POST 在“监听超时后恰好完成”时被额外发送一次的竞态，保留已经完成但尚未消费的响应。
- 修复解释器发现命令的阻塞输出读取绕过超时的问题。
- 修复停止扫描后延迟清理旧浏览器时误关新会话的问题；旧会话清理只作用于停止时捕获的会话。

## 发布验证

验证环境为 Windows、Java 21、Python 3.14、DrissionPage 4.1.1.2、无头 Edge。

| 范围 | 结果 |
| --- | --- |
| Java 全量测试 | 160 项通过：extender 154 项、mcp-core 6 项，零失败、零跳过 |
| Python 单元测试 | 22 项通过 |
| 本地真实浏览器测试 | 10 项通过，使用 loopback HTTP 服务及独立临时浏览器配置 |
| 正式 JAR | 全量重建，ZIP CRC、Manifest 版本、Java 21 字节码及浏览器资源一致性检查通过 |
| 缓存排除 | 最终 JAR 不含 `__pycache__`、`.pyc`、`.pyo` |

浏览器测试覆盖普通错误响应、401/412/413 Cookie 挑战、连续两次 401、自动刷新、HttpOnly Cookie、POST 正文保留、慢 POST 防重复，以及一个浏览器阻塞时另一独立浏览器继续执行且 Cookie 不串用。

Java 回归测试覆盖多 URL 导入、参数扫描混合模式、字典与占位符、流量隔离、历史恢复、菜单/面板初始化、队列调度、暂停/停止及浏览器会话隔离。

这些结果不等于所有业务页面均已验证。本次发布检查未在运行中的 Burp GUI 内重新逐项人工操作，也未验证 macOS/Linux 或所有浏览器版本；复杂业务挑战页仍可能需要单独适配。

### 复现测试

在项目根目录，使用 JDK 21：

```powershell
.\mvnw.cmd clean package
```

Python 单元测试默认不启动浏览器：

```powershell
python -B -m unittest discover -s extender/src/test/python -v
```

如需真实浏览器测试，使用已安装 DrissionPage 的 Python，并确保 Edge 可用：

```powershell
$env:OST_BROWSER_INTEGRATION = '1'
try {
    python -B -m unittest discover -s extender/src/test/python -v
} finally {
    Remove-Item Env:/OST_BROWSER_INTEGRATION -ErrorAction SilentlyContinue
}
```

## 升级及回退

1. 保存当前任务，备份 OST 工作目录中的配置、字典及历史数据库。
2. 停止任务并卸载旧扩展，再加载 `extender/target/OST-v1.2.6.jar`，避免同时启用开发版与正式版。
3. 浏览器请求需要可用的 Edge/Chrome，以及配置的 Python 环境中的 DrissionPage；普通 HTTP 请求不依赖浏览器组件。
4. 如需回退，卸载正式版后加载之前保留的 JAR；必要时恢复升级前的配置和数据库备份，不覆盖仍在使用中的数据库。

自定义位置使用编号标记，旧 `$$` 草稿需要改为对应编号并分配字典。单次参数扫描上限为 5000 个请求，开始时保存模板和字典快照。

本机验证产物 `OST-v1.2.6.jar` 的 SHA-256：

```text
0741f2b1bc3557046648cea9538964b68c2481e66cf6f4cc16f122e601e56679
```

重新构建时 ZIP 时间戳等因素可能导致哈希不同；此值标识本次实际验证的包。
